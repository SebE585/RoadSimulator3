# Contribution

---

## Workflow
1. Forker le dépôt
2. Créer une branche (`feat/xxx` ou `fix/xxx`)
3. Commiter avec convention (`feat:`, `fix:`, `docs:`…)
4. Push → Pull Request

---

## Bonnes pratiques
- Tests unitaires obligatoires (`pytest`)
- Respect du style (`ruff`, `black`)
- Documentation associée (`mkdocs`)
