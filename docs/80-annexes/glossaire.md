## Introduction

Ce glossaire rassemble et définit les principaux termes techniques et concepts employés dans le cadre du projet RoadSimulator3 (RS3). Il vise à faciliter la compréhension des documents associés ainsi qu’à uniformiser le vocabulaire utilisé par les contributeurs et utilisateurs. Les entrées sont présentées par ordre alphabétique pour une consultation aisée.

## Glossaire

### Accéléromètre  
Capteur mesurant l’accélération linéaire d’un objet dans un espace tridimensionnel. Utilisé pour détecter les mouvements et vibrations dans les systèmes embarqués.

### API  
(Applied Programming Interface) Interface de programmation permettant à différents logiciels de communiquer entre eux via des fonctions prédéfinies.

### CSV  
(Comma-Separated Values) Format de fichier texte simple utilisé pour stocker des données tabulaires, où chaque valeur est séparée par une virgule.

### Événement inertiel  
Phénomène détecté par des capteurs inertiels (accéléromètre, gyroscope) indiquant un changement de mouvement ou d’orientation.

### GNSS  
(Global Navigation Satellite System) Ensemble des systèmes de navigation par satellite permettant de déterminer la position géographique avec précision.

### Gyroscope  
Capteur mesurant la vitesse angulaire ou la rotation d’un objet autour d’un ou plusieurs axes.

### OSM  
(OpenStreetMap) Projet collaboratif de cartographie libre et ouverte, fournissant des données géographiques détaillées.

### OSRM  
(Open Source Routing Machine) Moteur de calcul d’itinéraires open source utilisant les données OSM pour planifier des trajets routiers.

### OSMnx  
Bibliothèque Python permettant de télécharger, modéliser et analyser les données OpenStreetMap pour des réseaux routiers.

### Parquet  
Format de fichier colonne optimisé pour le stockage et le traitement efficace de grandes quantités de données structurées.

### Pipeline  
Chaîne de traitement automatisée dans laquelle les données passent par plusieurs étapes successives pour être transformées ou analysées.

### Plugin  
Module additionnel qui étend les fonctionnalités d’un logiciel principal sans modifier son code source de base.

### Profil de simulation  
Configuration définissant les paramètres et conditions d’une simulation dans RS3, comme le type de véhicule ou les scénarios de conduite.

### RS3  
Abréviation de RoadSimulator3, plateforme de simulation de données routières et de mobilité.

### SRTM  
(Shuttle Radar Topography Mission) Données topographiques issues d’une mission radar spatiale fournissant des modèles numériques d’élévation.

### Stage  
Période de formation pratique ou projet encadré, souvent en entreprise, permettant d’appliquer les connaissances théoriques.

### Trajectoire  
Chemin suivi par un objet ou un véhicule dans l’espace au cours du temps, généralement représenté par une série de points géolocalisés.
